Detailed Description

Unit tests for the gradient direction computation.

  • This file contains bare-metal assertion tests to verify that the compute_direction function correctly maps Gx and Gy gradient values into the four discrete angular bins (0, 1, 2, 3) required for Non-Maximum Suppression.

Verifies behavior when both gradients are zero.

  • Tests the edge case where there is no change in pixel intensity. Based on the current implementation, if both Gx and Gy are exactly 0, the function falls back to assigning direction bin 3 (diagonal).
