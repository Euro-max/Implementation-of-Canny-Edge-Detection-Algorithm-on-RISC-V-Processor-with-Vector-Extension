\doxysubsection{Detailed Description}
Google Test suite for Sobel edge detection operator. 

Tests the \doxylink{sobel_8cpp_a6f7c3658f2307b3768bcce2eb3e3d3ab}{compute\+\_\+sobel()} function which computes horizontal and vertical gradients using 3x3 Sobel kernels.

Sobel kernels\+:
\begin{DoxyItemize}
\item Gx\+: \mbox{[}\mbox{[}-\/1,0,1\mbox{]}, \mbox{[}-\/2,0,2\mbox{]}, \mbox{[}-\/1,0,1\mbox{]}\mbox{]} (horizontal edges)
\item Gy\+: \mbox{[}\mbox{[}-\/1,-\/2,-\/1\mbox{]}, \mbox{[}0,0,0\mbox{]}, \mbox{[}1,2,1\mbox{]}\mbox{]} (vertical edges)
\end{DoxyItemize}
