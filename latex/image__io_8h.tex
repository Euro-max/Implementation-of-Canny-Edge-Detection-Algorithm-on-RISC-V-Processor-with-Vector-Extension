\doxysubsection{Detailed Description}
Declarations for raw image file I/O and aligned memory allocation. 


\begin{DoxyItemize}
\item This header defines utility functions for reading and writing raw 8-\/bit grayscale image data to and from disk. It also provides a specialized memory allocator to ensure all image buffers meet the strict alignment requirements necessary for high-\/performance vector processing. 
\end{DoxyItemize}
