\doxysubsection{Detailed Description}
Unit tests for gradient magnitude computation (L1 and L2 norms). 


\begin{DoxyItemize}
\item This file contains bare-\/metal assertion tests to verify the correctness of the magnitude calculations. It tests both the L1 (Manhattan distance) and L2 (Euclidean distance) implementations, ensuring they handle edge cases, stay within 8-\/bit bounds, and adhere to mathematical expectations. 
\end{DoxyItemize}
