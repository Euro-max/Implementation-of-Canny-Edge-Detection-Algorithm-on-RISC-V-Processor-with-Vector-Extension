\doxysubsection{Detailed Description}
Google Test suite for 5x5 Gaussian blur. 

Tests the \doxylink{gaussian_8h_a25d9fc356d85b9846432f07b4c113ee7}{gaussian\+\_\+blur\+\_\+5x5()} template function which applies a 5x5 Gaussian kernel for image smoothing. Verifies properties like constant preservation, energy conservation, and symmetry.
