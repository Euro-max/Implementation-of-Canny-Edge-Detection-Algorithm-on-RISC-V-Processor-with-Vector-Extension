Allocates a temporary int32\+\_\+t buffer on the stack via VLA (or the caller could pre-\/allocate it; here we use a static local to avoid heap allocation in the timed hot path — if image size is fixed this is safe).

\begin{DoxyWarning}{Warning}

\end{DoxyWarning}
