\doxysubsection{Detailed Description}
Google Test suite for gradient direction quantization. 

Tests the \doxylink{direction_8cpp_ae567c5694a1a6bfcf8a6b8e0d71319d6}{compute\+\_\+direction()} function which quantizes gradient orientation into 4 bins (0°, 45°, 90°, 135°). Uses Google Test framework for assertions.

Direction conventions\+:
\begin{DoxyItemize}
\item 0 → 0° (horizontal gradient / vertical edge)
\item 1 → 45° (diagonal edge, Gx/\+Gy same sign)
\item 2 → 90° (vertical gradient / horizontal edge)
\item 3 → 135° (diagonal edge, Gx/\+Gy opposite signs)
\end{DoxyItemize}
