\doxysubsection{Detailed Description}
Google Test suite for the Canny Edge Detection math kernels. 


\begin{DoxyItemize}
\item This file contains comprehensive unit tests for the Gaussian Blur, Sobel operators, Gradient Magnitude, and Gradient Direction functions. It verifies mathematical correctness, edge cases, and impulse responses. 
\end{DoxyItemize}
