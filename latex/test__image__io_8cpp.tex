\doxysubsection{Detailed Description}
Unit tests for raw image input/output operations and memory allocation. 


\begin{DoxyItemize}
\item This file contains bare-\/metal assertion tests to verify that image buffers are correctly allocated with strict memory alignment (for RVV vectorization) and that raw binary file reading and writing work flawlessly without data loss. 
\end{DoxyItemize}
