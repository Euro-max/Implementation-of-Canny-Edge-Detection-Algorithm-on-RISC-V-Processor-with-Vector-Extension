\doxysubsection{Detailed Description}
Assert-\/based tests for NMS, Double Thresholding, and Hysteresis. 


\begin{DoxyItemize}
\item This file contains bare-\/metal assertion tests to verify the final stages of the Canny Edge Detection pipeline. It ensures that edge thinning (NMS), pixel categorization (Double Thresholding), and edge connectivity tracking (Hysteresis) function mathematically correctly. 
\end{DoxyItemize}
