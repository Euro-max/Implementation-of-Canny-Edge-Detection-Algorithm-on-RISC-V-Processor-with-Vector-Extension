\doxysubsection{Detailed Description}
Implementation of raw image file I/O and aligned memory allocation. 


\begin{DoxyItemize}
\item Uses stdio (fopen/fread/fwrite) instead of C++ streams (ifstream/ofstream). WHY\+: C++ streams require more C++ runtime support which is problematic with riscv64-\/unknown-\/elf bare-\/metal toolchain + newlib. 
\end{DoxyItemize}
