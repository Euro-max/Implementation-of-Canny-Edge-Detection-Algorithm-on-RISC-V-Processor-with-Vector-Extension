Declarations for the Gaussian blur filter. 


\begin{DoxyItemize}
\item This header defines the template interface for a 5x5 Gaussian blur operation. By utilizing C++ templates, the filter can seamlessly operate on various data types (e.\+g., 8-\/bit integers for standard images, or floating-\/point types for higher precision pipelines) without duplicating the underlying convolution logic. 
\end{DoxyItemize}

\item Convolves the input image with a fixed 5x5 integer approximation of a Gaussian kernel. Boundary pixels are handled implicitly via zero-\/padding (out-\/of-\/bounds coordinates are ignored during accumulation).
