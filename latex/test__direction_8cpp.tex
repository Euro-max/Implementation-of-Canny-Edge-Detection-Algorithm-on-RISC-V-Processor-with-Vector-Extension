\doxysubsection{Detailed Description}
Unit tests for the gradient direction computation. 


\begin{DoxyItemize}
\item This file contains bare-\/metal assertion tests to verify that the compute\+\_\+direction function correctly maps Gx and Gy gradient values into the four discrete angular bins (0, 1, 2, 3) required for Non-\/\+Maximum Suppression. 
\end{DoxyItemize}
