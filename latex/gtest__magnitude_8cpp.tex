\doxysubsection{Detailed Description}
Google Test suite for gradient magnitude computation. 

Tests both L1 and L2 gradient magnitude computation functions. Verifies normalization, scaling, and range properties.

Implementation notes for compute\+\_\+magnitude\+\_\+l1\+:
\begin{DoxyEnumerate}
\item raw\mbox{[}i\mbox{]} = \texorpdfstring{$\vert$}{|}gx\mbox{[}i\mbox{]}\texorpdfstring{$\vert$}{|} + \texorpdfstring{$\vert$}{|}gy\mbox{[}i\mbox{]}\texorpdfstring{$\vert$}{|}
\item max\+\_\+raw = max of all raw\mbox{[}i\mbox{]}
\item output\mbox{[}i\mbox{]} = (uint8\+\_\+t)(raw\mbox{[}i\mbox{]} \texorpdfstring{$\ast$}{*} 255.\+0f / max\+\_\+raw) (normalized)
\item If max\+\_\+raw == 0, all output = 0
\end{DoxyEnumerate}

So the MAX pixel always maps to 255; everything else is proportional.
