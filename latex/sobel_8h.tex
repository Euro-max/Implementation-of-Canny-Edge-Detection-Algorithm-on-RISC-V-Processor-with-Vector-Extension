\doxysubsection{Detailed Description}
Declarations for the Sobel operator gradient computation. 


\begin{DoxyItemize}
\item This header defines the interface for calculating the spatial gradients of an image. The Sobel operator uses two 3x3 convolution kernels to estimate the derivative in the horizontal (Gx) and vertical (Gy) directions, which is a fundamental step in edge detection. 
\end{DoxyItemize}

Computes the horizontal and vertical gradients of an image using Sobel operators. 


\begin{DoxyItemize}
\item Applies the 3x3 Sobel kernels across the input image. Boundary pixels are handled implicitly by skipping out-\/of-\/bounds coordinates (equivalent to zero-\/padding). The resulting gradients are written out to separate contiguous arrays to optimize memory access patterns.
\item Uses int16\+\_\+t for gradients as it\textquotesingle{}s sufficient for 8-\/bit input to prevent overflow during the convolution accumulations.
