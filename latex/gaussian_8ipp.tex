\doxysubsection{Detailed Description}
Template implementation for a 5x5 Gaussian blur filter. 


\begin{DoxyItemize}
\item This file contains the template definition for applying a 5x5 discrete Gaussian blur convolution. The kernel approximates a Gaussian distribution to reduce image noise and high-\/frequency detail, which is a critical preprocessing step in edge detection pipelines. 
\end{DoxyItemize}

Applies a 5x5 Gaussian blur to a 2D image array. 


\begin{DoxyItemize}
\item Convolves the input image with a fixed 5x5 integer approximation of a Gaussian kernel. Boundary pixels are handled implicitly via zero-\/padding (out-\/of-\/bounds coordinates are ignored during accumulation). The final sum is normalized by dividing by 273 (the sum of all kernel weights) to preserve the overall brightness of the image.
