\doxysubsection{Detailed Description}
Declarations for gradient magnitude computation. 


\begin{DoxyItemize}
\item This header defines the interfaces for calculating the total edge strength (magnitude) from the horizontal (Gx) and vertical (Gy) gradients. It provides both the L1 (Manhattan) and L2 (Euclidean) norm implementations, allowing for a trade-\/off between computational speed and mathematical accuracy. 
\end{DoxyItemize}
