Computes and quantizes the gradient direction for every pixel. 

Quantizes gradient direction into 4 bins\+: 0\+: 0 degrees (Horizontal edge / Vertical gradient) 1\+: 45 degrees 2\+: 90 degrees (Vertical edge / Horizontal gradient) 3\+: 135 degrees


\begin{DoxyItemize}
\item This function evaluates the horizontal (Gx) and vertical (Gy) gradient components to determine the dominant edge direction. It uses an integer-\/based approximation for the tangent boundaries (22.\+5° and 67.\+5°) to map the continuous gradient angle into four discrete directional bins\+:
\item 0\+: Horizontal gradient (Vertical edge)
\item 1\+: 45-\/degree diagonal gradient
\item 2\+: Vertical gradient (Horizontal edge)
\item 3\+: 135-\/degree diagonal gradient
