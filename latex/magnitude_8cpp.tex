\doxysubsection{Detailed Description}
Implementation of gradient magnitude computation (L1 and L2 norms). 


\begin{DoxyItemize}
\item This file contains the algorithms for calculating the total edge strength from horizontal and vertical gradients. Both implementations use a robust two-\/pass approach\+: the first pass computes the raw magnitudes and finds the global maximum, while the second pass normalizes all values to the standard 8-\/bit image range \mbox{[}0, 255\mbox{]} to prevent data loss or overflow. 
\end{DoxyItemize}
