\doxysubsection{Detailed Description}
Implementation of the Sobel edge detection operator. 


\begin{DoxyItemize}
\item This file contains the scalar implementation of the 3x3 Sobel filter, which computes the spatial gradient of an image to identify regions of high spatial frequency (edges). 
\end{DoxyItemize}

Computes the horizontal and vertical gradients of an image using Sobel operators. 


\begin{DoxyItemize}
\item Applies the 3x3 Sobel kernels (Kx and Ky) across the input image using a standard 2D convolution. Boundary pixels are handled implicitly by skipping out-\/of-\/bounds coordinates (equivalent to zero-\/padding). The resulting gradients are written out to separate contiguous arrays to optimize memory access patterns for subsequent processing stages.
