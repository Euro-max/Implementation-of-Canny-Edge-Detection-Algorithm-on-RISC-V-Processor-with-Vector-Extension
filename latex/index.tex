 \hypertarget{index_autotoc_md5}{}\doxysection{\texorpdfstring{Project Overview}{Project Overview}}\label{index_autotoc_md5}
This project implements a highly optimized Canny Edge Detection pipeline targeted for bare-\/metal RISC-\/V architectures ({\ttfamily riscv64-\/unknown-\/elf}). The pipeline processes 8-\/bit grayscale images through a complete 7-\/stage algorithm, including Gaussian Blur, Sobel operators, and Non-\/\+Maximum Suppression.

A major focus of this implementation is performance optimization utilizing {\bfseries{RISC-\/V Vector (RVV) Extension intrinsics}} to accelerate spatial gradient computations and magnitude calculations, drastically reducing cycle counts for embedded vision applications.\hypertarget{index_autotoc_md6}{}\doxysection{\texorpdfstring{The Team}{The Team}}\label{index_autotoc_md6}

\hypertarget{index_autotoc_md22}{}\doxysection{\texorpdfstring{Phase 2 — Scalar Baseline Pipeline ✅}{Phase 2 — Scalar Baseline Pipeline ✅}}\label{index_autotoc_md22}
Clean, templated C++ implementation of the full 7-\/stage pipeline\+:


\begin{DoxyItemize}
\item {\bfseries{Image I/O}} — raw grayscale format ({\ttfamily width × height} bytes, no headers). Buffers allocated with {\ttfamily aligned\+\_\+alloc(64, ...)} for SIMD alignment.
\item {\bfseries{Gaussian Blur}} — 5×5 integer kernel (coefficients sum to 273), zero-\/padding boundary, 32-\/bit accumulator to prevent overflow. Templated on pixel type, accumulator type, and coefficient type.
\item {\bfseries{Sobel Gradient}} — 3×3 {\ttfamily Gx}/{\ttfamily Gy} kernels, output as separate {\ttfamily int16\+\_\+t} arrays (Structure-\/of-\/\+Arrays layout for efficient vectorization).
\item {\bfseries{Magnitude}} — both L1 ({\ttfamily \texorpdfstring{$\vert$}{|}\+Gx\texorpdfstring{$\vert$}{|}+\texorpdfstring{$\vert$}{|}\+Gy\texorpdfstring{$\vert$}{|}}) and L2 ({\ttfamily sqrt(Gx²+\+Gy²)}) implemented; pipeline uses L1 for speed. Two-\/pass normalization to {\ttfamily \mbox{[}0, 255\mbox{]}}.
\item {\bfseries{Direction}} — quantized to 4 bins (0°/45°/90°/135°) using integer cross-\/multiplication instead of {\ttfamily \doxylink{gaussian_8h_a25d9fc356d85b9846432f07b4c113ee7}{atan2()}} — a standard embedded optimization.
\item {\bfseries{Non-\/\+Maximum Suppression}} — thins edges to single-\/pixel width by suppressing non-\/peak pixels along the gradient direction.
\item {\bfseries{Hysteresis Thresholding}} — dual high/low threshold; weak edges are kept only if 8-\/connected to a strong edge pixel.
\end{DoxyItemize}

{\bfseries{Data Widening Chain (Gaussian)}}

To prevent integer overflow when accumulating 25 products in a 5×5 kernel\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{uint8\_t\ (pixels)\ →\ int32\_t\ (accumulator\ via\ vwmaccsu)}

\end{DoxyCode}


Worst case\+: 255 × 41 × 25 ≈ 261,000 — overflows int16\+\_\+t but fits int32\+\_\+t.

{\bfseries{Fixed-\/\+Point Division (replaces {\ttfamily vdiv})}}

Division by 273 (Gaussian normalization) uses a multiply-\/shift instead of slow vector division\+:


\begin{DoxyCode}{0}

\end{DoxyCode}
