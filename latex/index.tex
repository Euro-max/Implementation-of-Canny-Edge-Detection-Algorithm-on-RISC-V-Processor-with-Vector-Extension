 \hypertarget{index_autotoc_md18}{}\doxysection{\texorpdfstring{Project Overview}{Project Overview}}\label{index_autotoc_md18}
This project implements a highly optimized Canny Edge Detection pipeline targeted for bare-\/metal RISC-\/V architectures ({\ttfamily riscv64-\/unknown-\/elf}). The pipeline processes 8-\/bit grayscale images through a complete 7-\/stage algorithm, including Gaussian Blur, Sobel operators, and Non-\/\+Maximum Suppression.

A major focus of this implementation is performance optimization utilizing {\bfseries{RISC-\/V Vector (RVV) Extension intrinsics}} to accelerate spatial gradient computations and magnitude calculations, drastically reducing cycle counts for embedded vision applications.\hypertarget{index_autotoc_md19}{}\doxysection{\texorpdfstring{The Team}{The Team}}\label{index_autotoc_md19}

\hypertarget{index_autotoc_md34}{}\doxysection{\texorpdfstring{Phase 2 — Scalar Baseline Pipeline ✅}{Phase 2 — Scalar Baseline Pipeline ✅}}\label{index_autotoc_md34}
Implemented in clean, templated C++\+:


\begin{DoxyItemize}
\item {\bfseries{Image I/O}} — raw grayscale format (just {\ttfamily width\texorpdfstring{$\ast$}{*}height} bytes, no headers)
\item {\bfseries{Gaussian blur}} — 5×5 kernel, integer arithmetic, zero-\/padding boundary, templated on pixel/output/accumulator type
\item {\bfseries{Sobel gradient}} — 3×3 Gx/\+Gy kernels, output stored as separate int16 arrays (Structure-\/of-\/\+Arrays layout, for easier vectorization later)
\item {\bfseries{Magnitude}} — both L1 ({\ttfamily \texorpdfstring{$\vert$}{|}\+Gx\texorpdfstring{$\vert$}{|}+\texorpdfstring{$\vert$}{|}\+Gy\texorpdfstring{$\vert$}{|}}, fast) and L2 ({\ttfamily sqrt(Gx²+\+Gy²)}, accurate) implemented; pipeline uses L1
\item {\bfseries{Direction}} — quantized to 4 bins (0°/45°/90°/135°) using integer cross-\/multiplication instead of {\ttfamily \doxylink{gaussian_8h_a25d9fc356d85b9846432f07b4c113ee7}{atan2()}}
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+NMS \& Threshold\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}— Implemented edge thinning , double thresholding categorization, and hysteresis connectivity tracking to finalize edge segments.
\end{DoxyItemize}

\hypertarget{index_autotoc_md44}{}\doxysection{\texorpdfstring{Phase 6 — RVV Intrinsic Optimization 🔜 (next up)}{Phase 6 — RVV Intrinsic Optimization 🔜 (next up)}}\label{index_autotoc_md44}
Plan based on Phase 4 findings\+:


\begin{DoxyEnumerate}
\item {\bfseries{Gaussian}} — rewrite using RVV intrinsics. Process the image interior with no boundary checks (handle the 2-\/pixel border separately in scalar code) to avoid the structural issues that blocked auto-\/vectorization.
\item {\bfseries{Magnitude}} — keep the compiler\textquotesingle{}s auto-\/vectorized "{}find max"{} pass; hand-\/write RVV only for the normalization pass, using a fixed-\/point multiply+shift instead of floating-\/point divide.
\item {\bfseries{Sobel / Direction}} — lower priority, optional.
\item Verify scalar vs. RVV output match (±1 tolerance) at VLEN = 128, 256, and 512.
\end{DoxyEnumerate}
