\doxysubsection{Detailed Description}
RVV pipeline entry point\+: benchmarks scalar vs RVV at VLEN=128/256/512. 

\hypertarget{main__rvv_8cpp_autotoc_md0}{}\doxysubsubsection{\texorpdfstring{Purpose}{Purpose}}\label{main__rvv_8cpp_autotoc_md0}
This file replaces {\ttfamily \doxylink{main_8cpp}{main.\+cpp}} for the RVV build target. It runs the full 7-\/stage Canny pipeline twice per image\+:


\begin{DoxyEnumerate}
\item {\bfseries{Scalar path}} (same functions as Phase 4/5 benchmarks).
\item {\bfseries{RVV path}} (rvv\+\_\+gaussian + rvv\+\_\+magnitude; other stages unchanged).
\end{DoxyEnumerate}

After both runs it performs an {\bfseries{equivalence check}}\+: every output pixel of the RVV Gaussian and RVV magnitude is compared against the scalar baseline with ±1 LSB tolerance (to allow integer rounding differences).

The VLEN is set externally via the QEMU {\ttfamily -\/cpu rv64,v=true,vlen=N} flag — the binary itself never reads or assumes a VLEN value. Running this same binary at VLEN=128, 256, and 512 is the VLEN sweep.\hypertarget{main__rvv_8cpp_autotoc_md1}{}\doxysubsubsection{\texorpdfstring{Usage}{Usage}}\label{main__rvv_8cpp_autotoc_md1}
