Detailed Description

Google Test suite for Sobel edge detection operator.

Tests the compute_sobel() function which computes horizontal and vertical gradients using 3x3 Sobel kernels.

Sobel kernels:

  • Gx: [[-1,0,1], [-2,0,2], [-1,0,1]] (horizontal edges)
  • Gy: [[-1,-2,-1], [0,0,0], [1,2,1]] (vertical edges)
