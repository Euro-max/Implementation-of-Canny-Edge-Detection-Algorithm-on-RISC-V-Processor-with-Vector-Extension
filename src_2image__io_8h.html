Detailed Description

Declarations for raw image file I/O and aligned memory allocation.

  • This header defines utility functions for reading and writing raw 8-bit grayscale image data to and from disk. It also provides a specialized memory allocator to ensure all image buffers meet the strict alignment requirements necessary for high-performance vector processing.

Allocates a dynamically sized, memory-aligned image buffer.

  • This function guarantees that the starting address of the returned buffer is aligned to a 64-byte boundary. This is critical for maximizing memory throughput and preventing unaligned access faults when using RISC-V Vector (RVV) load/store instructions in the downstream processing pipeline.
  • Parameters
    widthWidth of the image to allocate in pixels.
    heightHeight of the image to allocate in pixels.
    Returns
    A 64-byte aligned pointer to the newly allocated uint8_t buffer.
    Allocates a dynamically sized, memory-aligned image buffer.
  • 64-byte alignment is required for RVV vector loads/stores to ensure optimal memory throughput and avoid alignment faults during hardware vectorization.
  • Parameters
    widthThe width of the image buffer to allocate.
    heightThe height of the image buffer to allocate.
