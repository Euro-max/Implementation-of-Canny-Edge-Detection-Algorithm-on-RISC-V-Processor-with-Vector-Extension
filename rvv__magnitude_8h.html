RVV-accelerated L1 gradient magnitude with global normalisation.

Two-pass algorithm:

  • Pass 1: temp[i] = |Gx[i]| + |Gy[i]|, track max.
  • Pass 2: output[i] = (uint8_t)(temp[i] * 255 / max).

Results match compute_magnitude_l1 within ±1 LSB (integer vs float rounding difference in the normalisation step).
