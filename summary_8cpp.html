Detailed Description

Cycle results analyzer and pipeline optimization advisor.

  • Reads performance cycle counts from various compiler optimization levels (e.g., -O0 through -Ofast) across the 7 stages of the Canny Edge Detection pipeline. Applies Amdahl's Law to calculate the percentage of total execution time spent in each stage and outputs prioritized advice on which stages would benefit most from RISC-V Vector (RVV) Extension vectorization.
