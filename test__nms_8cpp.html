Detailed Description

Assert-based tests for NMS, Double Thresholding, and Hysteresis.

  • This file contains bare-metal assertion tests to verify the final stages of the Canny Edge Detection pipeline. It ensures that edge thinning (NMS), pixel categorization (Double Thresholding), and edge connectivity tracking (Hysteresis) function mathematically correctly.

◆ test_hysteresis()

void test_hysteresis ( )

Verifies the hysteresis edge tracking algorithm.

  • Tests the connectivity rules for weak edges. A weak edge (128) that is connected to a strong edge (255) should be promoted to a strong edge (255). An isolated weak edge with no strong neighbors should be discarded (0).

◆ test_nms_suppression()

void test_nms_suppression ( )

Verifies that Non-Maximum Suppression (NMS) keeps local maxima.

  • Simulates a single sharp peak in a local 3x3 neighborhood. Evaluates if the center pixel (the maximum) is preserved while all adjacent pixels along the gradient direction are suppressed to 0.

◆ test_threshold()

void test_threshold ( )

Verifies the double thresholding categorization logic.

  • Tests whether pixels are correctly binned into three categories based on a low and high threshold:
  • Below low threshold -> Suppressed (0)
  • Between thresholds -> Weak Edge (128)
  • Above high threshold -> Strong Edge (255)
